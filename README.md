# stacksvg

Stack color svg values and contrast-safe presentation helpers.

**Site:** https://theworker02.github.io/stacksvg/

## Install / run

```bash
git clone https://github.com/theworker02/stacksvg.git
cd stacksvg
node src/cli.js
node --test
```
